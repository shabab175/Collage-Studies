# Easy notes: Chaucer to the Elizabethan Age

These notes explain all 15 textbook units in small steps. They use simple language while keeping the literary terms needed for MA English. Each file links to its full textbook unit.

## How to study

1. Read “The chapter in one sentence” and the opening picture.
2. Work through one section at a time. Explain it aloud in your own words.
3. Try the quick-check questions before reading their answers.
4. Use the exam-answer guidance to plan a paragraph, then return to the full unit for textual evidence and quotations.

The notes are learning aids, not line-by-line commentaries or complete assignment submissions. Distinguish a fictional speaker’s views from the author’s views, and a historical writer’s assumptions from present-day facts. Where an older survey uses broad labels, these notes add qualifications rather than repeat them as universal rules.
